The Settings panel is a tab inside the left panel. Open the left panel with
`SUPER + L` and select **Settings**. The panel keeps a category rail on the
left that follows the scroll position, and a searchable list of sections on the
right.

Values are persisted by the Quickshell `Settings` singleton to:

```text
~/.cache/quickshell/settings/settings.json
```

The shell reads the file at startup and rewrites it after changes. The file is
an implementation detail: prefer the panel, because it normalizes invalid
values and updates running widgets. Editing the JSON while the shell runs can
be overwritten.

## Sections

| Setting | Default | Notes |
| --- | --- | --- |
| Orientation | Top | Top or bottom edge for the bar. |

`barFullWidth`, reveal pressures) and is covered in [Bar](/docs/configuration/bar).

### User Agents

Editable user-agent strings for Booru, MangaDex, MangaLib, Waifu and Fastfetch
requests. The panel can copy each value.

### API Keys

Stores credentials for the optional integrations:

- OpenRouter user and API key (ChatBot)
- Danbooru user and key
- Gelbooru user and key
- Safebooru user and key
- Wallhaven API key (optional; unlocks NSFW results)

The ChatBot has its own provider setting and an optional "notify on reply"
toggle. Manga and Booru features are optional; the desktop works without them.

<Callout type="warning" title="Keys are stored locally as plain text">
API keys live in `settings.json` in your home directory. They are not encrypted
and they are not synced by ArchEclipse. Do not commit that file.
</Callout>

### Hyprland

This section edits a curated set of Hyprland leaves:

- general: border size, gaps in/out
- decoration: rounding, active/inactive opacity
- decoration blur: enabled, size, passes, xray
- decoration shadow: enabled, range, render power
- Game Mode: disables blur and animations for performance
- Blue Light Filter: on/off, temperature (1000–6500 K), auto schedule with start/end times

**Apply Hyprland Settings** writes one small Lua file per leaf to
`~/.config/hypr/config/custom/` and runs `hyprctl reload`. The files are named
with underscores (`decoration_blur_size.lua`, for example), so they load after
the tracked base modules. **Reset to Default** is a global reset: it restores the
panel's built-in defaults for shell and Hyprland values, then persists them. Run
**Apply Hyprland Settings** afterwards to write the Hyprland side.

<Callout type="note" title="Only curated leaves are editable here">
For window rules, input devices, monitors, gestures and other sections, edit the
Lua modules described in [Configuration](/docs/configuration).
</Callout>

### Recording

These values are read by `screenrecord.sh` through gpu-screen-recorder:

| Setting | Default |
| --- | --- |
| Video codec | `auto` |
| Quality | `very_high` |
| Color range | `limited` |
| Audio codec | `opus` |
| Frame rate | 60 |
| Frame rate mode | `auto` |
| Record cursor | on |
| Output device | `default_output` |
| Input device | `none` |
| Directory | `~/Videos/ScreenRecords` |
| Container | `mp4` |

Video codec, quality and container choices are validated against
gpu-screen-recorder. For example, WebM requires VP8, VP9 or AV1, and FLV requires
H.264. Changes apply on the next recording.

## Resetting

The **Reset to Default** button in the Hyprland section is a global reset for the
shell settings and the Hyprland slider values. Some reset values differ from the
fresh-install defaults in `theme/Settings.qml` (for example
`rightPanelWidth = 250` and `uiPad = 8` after a reset, versus 350 and 6 for a
new profile). To reset one area, set the values yourself or delete the settings
file while the shell is stopped, which makes the singleton fall back to its
built-in defaults on the next start.

<Callout type="danger" title="Stop the shell before deleting settings">
`rm ~/.cache/quickshell/settings/settings.json` while Quickshell is running will
usually be undone by the next persist. Stop the shell first, or use the panel.
</Callout>
